# 截图目录

把发布用截图放在这里，文件名按下面来：

| 文件 | 内容 |
| --- | --- |
| `overview.png` | 概览：正文框、投递按钮、自动开关 |
| `frame.png` | 悬浮图片框：页码、翻页箭头、三点菜单 |
| `fullscreen.png` | 右侧栏全屏看图 |
| `workbench.png` | 工作台：提示词、原文锚点、连续图 |
| `gallery.png` | 图库：当前会话 / 收藏 / 回收站 |
| `workflow.png` | 工作流或 LoRA（可选） |
| `follow.gif` | 滚动正文自动切图（可选） |

要求：

- 用干净的演示会话，不出现真实聊天、文件路径、token。
- 深色主题为主，宽度 1440–1920，几张图保持一致。
- PNG / JPG 单张尽量小于 1.5MB；GIF 尽量小于 5MB。
- 图片放好后，在根目录 `README.md` 里引用。
