## 换图时的要求

- 用干净的演示会话，不出现真实聊天、文件路径、token。
- 深色主题，几张图风格保持一致。
- 组合图两张并排拼成 1476 宽即可。
- 文字多的存 PNG（更清晰），画面为主的存 JPEG q92（体积小很多）。
- 单张尽量小于 400 KB，整个目录控制在 2 MB 以内——它们会跟着 npm 包一起发。

```powershell
pwsh -File tools/prep-images.ps1
```
