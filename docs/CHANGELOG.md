# 更新记录

## 0.2.1 — 首个公开发布

第一个放到 npm / 插件市场里的版本，功能面就是 README 里描述的这一整套：

- **自动出图**：捕获会话正文 → 投递到提示词会话 → 按规则切分 → 调本地 ComfyUI 出图 → 归档回 DSH。「自动投递正文」「自动出图」可分别开关，悬浮球 **A** 是总开关。
- **投递与来源**：正文来源与提示词来源分开设置，默认跟随当前会话，也可指向本进程或另一台 DSH 的会话；概览里的正文框默认留空，手写内容只在点「投递最新正文」时优先使用；附加消息可放正文最上面或最下面，投递成功后自动留空。
- **看图**：右侧栏面板、全屏看图、悬浮球、悬浮图片框。翻页、页码、下载、收藏、刷新、删除、圆角切换；删除当前图优先停到下一张；全屏与悬浮框的切图状态同步，切标签再回来位置不变。
- **跟图**：滚动正文自动切图、连续图按段落比例拆位置、光标跟图、手动偏移、清空定位。
- **工作台**：内置格式 / 全部匹配 / 自定义标签三种提示词方式；多套正负面、标题、原文锚点、分辨率；连续图、LoRA、随机种子、输出节点裁剪。
- **图库**：当前会话 / 全部 / 收藏夹 / 回收站，每页 9 张三列，收藏是复制副本。
- **工作流与 LoRA**：导入 ComfyUI API JSON、占位符与节点映射、解析预览、干跑；LoRA 堆 / 单 LoRA / Power / Stacker / Tag，可改名、调强度、保存到工作流。
- **界面**：日间 / 夜间、窄栏布局、轻提示、出图完成提示。
- **安装**：`dsh plugin --profile web add dsh-airp-comfy-bridge`；本地目录开发用 `node tools/install.mjs --apply`。需要本地 ComfyUI，适用于 DSH 0.2.x。
