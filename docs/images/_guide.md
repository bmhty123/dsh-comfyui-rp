## 换图时的要求

- 用干净的演示会话，不出现真实聊天、文件路径、token。
- 深色主题，几张图风格保持一致。
- 侧栏竖图宽度 700–800 就够；全屏横图 1600 宽以内。
- 文字多的截图存 PNG（更清晰），画面为主的存 JPEG q90（体积小很多）。
- 单张尽量小于 300 KB，整个 `docs/images` 控制在 1 MB 以内——它们会跟着 npm 包一起发。
